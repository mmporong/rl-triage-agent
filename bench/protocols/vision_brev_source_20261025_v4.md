# Brev 영상 자료 수집 사전등록 v4

v3은 GPU 실행 전에 seed 입장 검사에서 멈췄다. 로컬로 회수한 v2 실행 기록의
상위 경로 `vision-source-s2200-s2201-20261025b`가 seed 2200·2201의 사용으로 검출됐다.
실제 완료 학습은 점검용 seed 2202의 20회 학습이며 핵심 학습·고정 평가는 실행하지 않았다.
v2·v3 사전등록과 기록을 유지하고, 기존 seed 검사 규칙을 그대로 사용한다.

새 핵심 seed는 2210·2211이며 실행 직전 로컬·원격 미사용 검사를 통과해야 한다.
별도 실행 전 점검 seed는 미실행 상태인 2203이다.
runtime 식별자는 `vision-source-20261025d`로 고정해 계획상의 핵심 seed를
점검 실행의 상위 경로에 넣지 않는다. 결과를 관찰한 뒤 정책 성능 때문에 바꾸는 seed가 아니다.

- 소스: `vision_brev_source_20261025_v4.json`.
- 렌더: `vision_brev_render_20261025_v5.json`.
- 실행 전 점검: `vision_brev_preflight_20261025_v4.json`.

이 파일들과 결합 코드를 커밋한 뒤 실행한다.
이 판의 예측·성공/실패 기준·결과 문구·시스템 의존성 검사·교정 승인 경계는
[v3](vision_brev_source_20261025_v3.md)을 그대로 적용하되, 핵심 seed 표기만 2210·2211로 바꾼다.
정상·결함·교정 각 두 건, 환경 4,096개·300회 갱신 여섯 건 상한을 유지한다.
20회 점검은 환경 실행 확인이며 성능 표본에 합산하지 않는다.

소유 VM과 비용 시작 시각도 유지한다. v2 시작 요청부터의 전체 경과 시간에 대해
20 USD compute 상한을 적용하며, 이전 점검·실패·대기·회수 비용을 제외하지 않는다.
