[서비스 명]
RL Triage Agent (Isaac Lab 학습 실패 원인 추적 에이전트)

[해결하고자 했던 문제]
로봇 회사 개발자는 NVIDIA Isaac Lab 시뮬레이터에서 강화학습으로 로봇에게 걷는 법을 가르칩니다. 설정 여러 개를 바꿔 돌린 학습이 실패하면 어느 설정 때문인지 알기 어려워, 하나씩 되돌려 가며 다시 학습해 봐야 합니다. 엉뚱한 곳을 고치다 며칠이 지나기도 합니다. 저희 팀도 로봇개(Unitree Go2) 학습에서 원인과 무관한 설정을 세 번 연속 고쳤고, 증상이 처음 기록된 뒤 진짜 원인을 밝히기까지 12일이 걸렸습니다. 이 분석을 AI에게 맡길 때는 AI가 통과 기준을 낮추는 식으로 문제를 덮지 못하게 막는 것도 필요합니다.

[서비스 소개 및 주요 기능]
RL Triage Agent는 실패한 학습 기록을 받아 원인을 찾아 주는 AI 에이전트입니다. "이 학습이 왜 실패했는지 찾아줘"라고 하면 에이전트가 조사 순서를 스스로 정하고 도구를 골라 씁니다. 정상 학습과 지표를 비교하고, 수상한 그래프를 불러오고, 필요하면 분석 코드를 써서 실행합니다. 마지막에는 가장 의심되는 원인과 근거 수치, 확인을 위해 바꿔 볼 설정 하나를 보고서로 남깁니다. 사람이 승인하면 그 설정 하나만 바꿔 Isaac Lab에서 다시 학습하고, 로봇이 정상으로 돌아오는지로 진단을 확인합니다. 에이전트는 NVIDIA OpenShell 격리 환경 안에서만 움직여 학습 설정과 통과 기준을 고칠 수 없고, 권한을 더 달라는 요청은 openshell-prover가 검사해 허용 범위를 넘으면 자동으로 거절합니다. 일부러 오류 10종을 넣은 시험에서 원인 유형을 10건 중 6건 맞혀, 같은 모델에 한 번 질문하는 방식(2건)보다 정확했습니다.

[활용한 핵심 기술 및 AI 모델]
NVIDIA Nemotron 3 Super 120B (build.nvidia.com API, 도구 호출과 추론)
NVIDIA NeMo Agent Toolkit 1.9 (tool_calling_agent 워크플로, 사용자 정의 도구 7개)
NVIDIA OpenShell 0.1.1 (커스텀 샌드박스 이미지, Landlock 파일 정책, L7 REST 네트워크 정책, NVIDIA provider 자격증명 주입)
openshell-prover 0.1.1 (권한 확장 요청의 SMT 증명, 반례 기반 자동 거절)
NVIDIA Skills (skills-lock.json: nemo-rl-auto-research, nemoclaw-user-guide, nemotron-policy-generator / 자체 스킬 isaaclab-rl-triage)
NVIDIA Isaac Lab 2.1.1, Isaac Sim 4.5 (Unitree Go2 결함 주입 벤치마크, 재평가 재학습, 녹화)
Python, uv, Docker, WSL2, RSL-RL PPO
