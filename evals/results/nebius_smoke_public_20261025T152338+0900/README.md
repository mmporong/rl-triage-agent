# Nebius 제한 연동 시험 — 2026-10-25

공개 `bench/runs/c01_s42.telemetry.json`으로 Nemotron 3 Super의 인증·도구 호출·로컬 지표 조회·후속 응답을 확인했다. 진단 정확도나 교정/학습 성능 평가는 수행하지 않았다.

- 코드: `8eb2517930937e3971b4a024b9b57546bb12fc93`
- 추론 2회: 첫 응답 `tool_calls`, 로컬 입력 검사 후 둘째 응답 `stop`.
- 입력 1,225토큰, 출력 803토큰. 카탈로그 입력 $0.30/백만, 출력 $0.90/백만으로 계산하면 **$0.0010902**다. 실제 확정 청구액이 아니다.
- 실행 전 예약 상한 합계 **$0.0131442**, 총 허용 상한 **$0.05**, 자동 재시도 0, 요청당 출력 최대 4,096토큰으로 제한했다. 실제 두 요청의 입력 토큰은 예약 입력 한도 이하였다.
- 모델 호출은 체험 $1보다 작은 예산에서 종료했다. 화면의 Usage는 아직 요청을 표시하지 않아 실제 청구 정산까지 확인한 것으로 쓰지 않는다.

## 추가 사용 차단

이번에 만든 시험용 키를 폐기했고 같은 키의 모델 조회가 **HTTP 401**로 거부되는 것을 확인했다. 로컬 보안 파일에서 해당 키 할당을 제거했으며 다른 자격증명은 보존했다. 현재 프로젝트 UI의 API 키 목록은 비어 있다. GPU·전용 endpoint·백그라운드 추론 작업을 생성하지 않았다.

계정에는 카드가 등록되어 있고 공식 문서는 음수 잔액의 자동 청구를 설명한다. 확인한 화면/API 키 발급 화면에는 달러 지출 hard cap이나 자동 청구 중지 옵션이 없었다. 따라서 계정 전체의 자동 청구가 꺼졌다고 주장하지 않는다. 현재 시험 키로 추가 API 호출이 가능한 경로를 없앤 상태다. 향후 새 키나 Playground 사용을 다시 허용하면 별도 사용이 발생할 수 있다.

## 응답 품질의 한계

도구 호출과 숫자 인용은 확인됐지만 모델이 시계열의 `n=100`을 `100 episodes`로 표현했다. 이 단위 해석은 확정할 근거가 없으므로 진단 품질 통과로 취급하지 않는다. 원 응답은 수정하지 않고 보존했다. 다음 제품 단계에서는 측정 단위를 입력 계약에 명시하고 근거 밖 해석을 검토해야 한다.
