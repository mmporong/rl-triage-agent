# Nebius 제한 연동 시험 독립 검증

검증일: 2026-10-25 KST
검증 범위: 저장된 연동 시험 원문, 비용 계산, 로컬 자격증명 제거 상태, 공식 크레딧·결제 문구, 공개 기록의 과장·비밀정보 포함 여부. 추가 API 요청은 수행하지 않았다.

## Verdict

**PASS — 제한된 연동 시험과 기록 정확성**

Nemotron 3 Super의 계정 카탈로그 확인, 첫 응답의 도구 호출, 로컬 `inspect-run`, 둘째 응답의 정상 종료가 저장된 원문과 실행 프로토콜에서 이어진다. 실제 사용량과 단가 계산, 실행 전 예약 상한도 재계산 결과와 일치한다. 시험 키 제거 뒤의 차단 범위와 계정 결제의 남은 위험을 문서가 구분하므로, 이 결과는 연동 확인 증거로 승인한다.

이 판정은 계정 전체에서 앞으로 비용이 절대 발생하지 않는다는 보증이 아니다. 카드 자동 청구는 비활성화되지 않았고 달러 기준 계정 hard cap도 확인되지 않았다. 이번 시험 키를 폐기하고 로컬 할당을 없애, 같은 경로의 후속 호출을 막은 범위만 확인됐다.

## Evidence

- `summary.json`, `response-1.json`, `response-2.json`, `request-protocol.json` — 요청은 2회다. 첫 응답은 `finish_reason=tool_calls`와 `inspect_training_run({"case_id":"c01"})`, 둘째 응답은 `finish_reason=stop`과 비어 있지 않은 결과를 보존한다.
- 로컬 `uv run rl-triage inspect-run c01 --workspace ...` 재검사 — 원본 SHA-256 `737ba465...b943`, `reference_status=absent`, 첫 3개 지표가 `tool-output.json`과 일치했다. 저장소 HEAD도 기록한 `8eb2517930937e3971b4a024b9b57546bb12fc93`과 같았다.
- 토큰·가격 재계산 — 입력 `456+769=1,225`, 출력 `46+757=803`; 입력 `$0.30/1M`, 출력 `$0.90/1M`을 적용하면 `$0.0010902`다. 이는 Usage UI나 청구서가 확정한 금액이 아니라 카탈로그 단가 기반 계산치다.
- 예약 상한 재계산 — 요청별 `$0.0064245`와 `$0.0067197`의 합은 `$0.0131442`이며 `$0.05`보다 작다. 클라이언트는 최대 2회, 요청당 출력 4,096토큰, SDK 재시도 0을 적용했다.
- `request-protocol.json` 재구성 검사 — 각 요청을 실행 클라이언트와 같은 Python JSON 직렬화로 계산한 UTF-8 바이트 수에 8,192 프레이밍 토큰을 더한 값이 각각 9,127과 10,111로 `summary.json`의 예약 입력 한도와 정확히 일치했다.
- `model-catalog.json` — `nvidia/nemotron-3-super-120b-a12b`, `tools` 지원, 저장한 입력·출력 단가가 비용 계산과 일치한다.
- `revocation.json`, `account-safety.json` — 시험 키 폐기 후 같은 키의 모델 조회가 HTTP 401이었고 프로젝트 키 목록은 빈 상태로 기록됐다. 현재 `$HOME/.config/nvidia/env` 권한은 `0600`이며 `NEBIUS_API_KEY` 할당 행이 없다.
- 공개 파일 비밀정보 검사 — 시험 결과와 `docs/NEBIUS-HACKATHON.md`에서 API 키 값으로 보이는 패턴을 찾지 못했다. 신청 항목의 필드 이름만 있고 실명·이메일 값은 없다.
- `artifact-hashes.json` — 열거된 13개 파일의 현재 SHA-256을 다시 계산해 모두 일치했다.
- 로컬 포트 검사 — 일회성 콜백 포트 44451에 남은 listener가 없었다. 지속 추론 프로세스의 부재를 보조 확인했다.
- 공식 행사 리소스 — 해커톤 신청 폼의 Token Factory `$25`와 무료 Builder Program 가입의 추가 `$25` 안내를 2026-10-25에 재확인했다: <https://nebiusglobalaihackathon.devpost.com/resources>
- 공식 Builder Program — 회원 혜택에 Token Factory `$25`가 명시돼 있다. 프로그램은 무료지만 혜택은 자격·가용성·개별 조건을 따른다: <https://dev.nebius.com/builders>
- 공식 결제 문서 — 가입 시 `$1` 체험 크레딧과 30일 유효기간, 카드 자동 청구 조건을 재확인했다: <https://docs.tokenfactory.nebius.com/other-capabilities/billing-new>
- `source-notes.md` — 과거 선불 결제 문서와 현재 `billing-new`의 자동 청구 설명이 충돌할 수 있음을 기록했고, 현재 문서와 계정 UI보다 과거 문서를 우선하지 않았다.

## Gaps

- Usage 화면에 요청이 아직 반영되지 않아 `$0.0010902`를 확정 청구액이나 실제 차감액으로 대조하지 못했다.
- 프로젝트 키 목록이 비었다는 UI 관찰과 폐기 키의 HTTP 401은 저장 기록으로 검토했다. 폐기된 비밀값을 복구하거나 추가 인증 요청을 보내 재현하지 않았다.
- 해커톤 `$25`와 Builder Program `$25`는 공식 제공 안내만 확인했다. 신청, 약관 동의, 발급, 계정 잔액 적용은 완료되지 않았다.
- 전체 NAT 워크플로, 교정·재학습 루프, OpenShell의 Nebius 호스트 허용은 이번 시험 범위 밖이다.

## Risks

- 카드 계정은 잔액이 음수가 되거나 결제 임계값에 도달하면 자동 청구될 수 있다. 새 API 키 발급, Playground 사용, 다른 프로젝트 자격증명은 새로운 비용 경로가 된다.
- 모델은 지표의 `n=100`을 `100 episodes`로 표현했지만 로컬 검사 출력은 `n`의 의미를 episode로 확정하지 않는다. 따라서 진단 정확도는 승인하지 않고 연동만 승인한다.
- 공식 혜택은 신청 시점의 자격, 가용성, 약관에 따라 달라질 수 있다. 현재 계정에 합계 `$50`이 이미 지급됐다는 뜻으로 사용하면 안 된다.

## Stop condition

도구 호출 연동, 비용 경계, 키 폐기 후 차단, 기록 정합성, 공식 크레딧 안내를 확인했고 추가 API 호출 없이 검증 가능한 범위를 소진했다. 다음 유료 가능 실행은 새 키와 별도 예산 경계를 마련한 뒤 새 검증 대상으로 다룬다.
