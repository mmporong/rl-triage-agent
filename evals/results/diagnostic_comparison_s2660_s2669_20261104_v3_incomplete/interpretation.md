# 중단된 진단 비교 기록

원래 10사례·40arm 중 16arm이 종료되고 case-05의 첫 검사에서 임대 파일 읽기 PermissionError로 중단됐다. 실행 상태는 stopped_integrity_failure이며 전체 비교 완료가 아니다. 원래 CLI는 종료 코드0을 반환했지만 결과 본문의 실패 판정을 보존했다. 이후 판은 이 오류에서 비영 종료 코드를 반환한다.

정상 두 사례의 8arm은 모두 호스트 gate가 모델·검사를 막았다. 이를 모델의 정상 판별 성공으로 세지 않는다. baseline 4arm은 보상 사례에서 노출된 세 검사가 정상인 뒤 미확정이었다.

모델 요청 4회는 HTTP200이었다. 네 방식에 같은 12개 facts를 제공했지만, prompt가 fact_ids 빈 목록 예시를 보여주고 host만 최소1개를 요구한 계약 불일치가 확인됐다. host의 contract_invalid/HOLD 기록은 그대로 남기며 모델의 판단 품질·열등성이나 명시 계약 준수율로 해석하지 않는다. 이 요청들은 재호출하지 않는다.

실패한 SDK interpreter 시도1회는 앱 시작 전 실패했다. 당시 실행기가 실패 소유 wall을 봉인하지 않아 그 값은 unknown이며0으로 만들지 않는다. 별도 controller·sampler 시간도 소유 wall을 대신하지 않는다. 이후 실행기는 실패 반환과 무결성 종료 비용을 봉인한다.

보존된 집계기는 당시 source checkout에서 실행했다. 최초 scoring key의 생산자·소비자 스키마가 달라 정적 결함→probe 대응을 유지한 형식 어댑터를 별도로 적용했다. 원래 scoring key·실행·모델 응답은 수정하지 않았다. 집계 표의 계획 분모40과 미시작23을 유지한다.

이 폴더는 기능 실패와 비용 누락의 재현 기록이다. 미실행 case-05∼10의 속행은 새 코드·계약·사전등록 판에서 수행하며 이 결과와 구분한다. 후속 회복은 이 실행에서 수행하지 않았다.
