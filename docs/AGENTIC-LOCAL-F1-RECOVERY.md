# 로컬 F1 진단 후 회복 평가

Nemotron 3.5 Super VL이 개발 seed 2221에서 `P_reward` 검사를 골랐고, 로컬 256환경 200스텝 검사는 NONE을 정상, F1을 비정상으로 갈랐다. 이어진 등록 판단은 `restore_body_frame_reward` 교정을 제안했다.

승인된 교정을 적용한 뒤 fresh seed 3221로 300회 재학습하고 26조건 고정 평가를 수행했다. 판정은 **not_recovered**이다. NONE과 교정 정책의 선형 속도 RMSE는 각각 0.148632 m/s와 0.144703 m/s였고, 평균 생존 시간은 20.000000초와 19.989365초였다. 선형 속도 비율 0.973570, 생존 비율 0.999468, 낙상률 0.000962은 기준을 통과했지만, yaw 오차 비율 1.619850은 상한 1.1719를 넘어 회복으로 판정되지 않았다. 전체 학습과 평가 수치는 실행 원문에서 가져왔다.

이번 결과는 이미 본 개발 seed 2221의 진단과 새 재학습 seed 3221의 회복 평가를 잇는다. API 11의 연결 실패는 의미 판단 전 인프라 종료로 보존했고, API 12의 유효 판단만 교정 제안에 사용했다. 이 결과만으로 LLM 우위나 영상 근거의 추가 효과를 주장하지 않는다.

사후 조건별 기술에서는 yaw 제곱오차 증가 53315.85127258301 중 50137.94189453125, 즉 94.0394661%가 명령 `[0, 0, -1]`과 `[0, 0, 1]` 두 조건에 모였다. 교정 readback에서는 보상 함수의 교정 전후 코드 SHA가 같고 `fault_present_after`가 false임을 확인했다. 나머지 원인은 아직 확정하지 않았으며, 이 관찰로 회복 기준을 바꾸거나 해당 조건을 제외하지 않는다.

## 같은 seed 정상 대조의 후속 결과

[새 정상 대조 실험](SAME-SEED-RECOVERY-CONTROL.md)에서는 결함과 교정을 적용하지 않고 seed 3221을 같은 설정으로 300회 학습했다. 새 정상 정책과 위 교정 정책은 checkpoint 바이트 및 26조건 평가 수치가 같았다. 정상 대조도 기존 seed 2221 참조 대비 yaw 비율 1.619850으로 기준을 넘었다. 사전등록 분기는 `seed_or_command_coverage_consistent`이며, 이 조건에서 교정 실행은 같은 seed 정상 학습을 재현했다. 어느 학습 요소가 회전 약점을 만들었는지는 확정하지 않는다. 위 원래 판정은 `not_recovered`로 보존하며 새 모델 회복 성공에 합산하지 않는다.
