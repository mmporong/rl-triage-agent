# Brev 정상 학습 호환성과 처리량

고정한 Go2 정상 학습을 RTX PRO 6000 96GB 인스턴스와 L40S 48GB 인스턴스에서 실행했다. 두 인스턴스 모두 새 seed 두 개의 300회 학습을 완료했다. 이 파일럿의 범위는 정상 학습의 호환성과 처리량이다.

## 고정한 조건

[사전등록](../bench/protocols/brev_compute_pilot_v1.json)은 측정 전에 커밋 `47a85b824b70f92f7258d1b4f327e17e8c76f022`로 고정했다. 기존 L40S 설치 기록을 참고해 설계했으며, 과거 처리량 수치를 이번 결과에 합치지 않았다.

실행 전 저장소 기록과 로컬 Isaac Lab 로그를 검사해 세 seed의 기존 사용 기록이 없음을 확인했다. 같은 seed를 두 인스턴스에서 쓰는 짝 비교를 사전등록했다.

## 측정 결과

학습 시간은 `OnPolicyRunner.learn` 호출 구간이다. 자식 전체 시간은 프로세스 시작부터 종료·정리까지이며, 설치 시간은 별도로 기록했다.

| 인스턴스 | Stop 지원 | seed 2180 학습(초) | seed 2181 학습(초) | 학습 중앙값(초) | 자식 전체 중앙값(초) |
| --- | --- | ---: | ---: | ---: | ---: |
| Verda RTX PRO 6000 96GB | 미지원 | 138.6 | 134.8 | 136.7 | 149.1 |
| Crusoe L40S 48GB | 지원 | 187.6 | 182.1 | 184.9 | 200.2 |

| 환경 차이 | RTX 인스턴스 | L40S 인스턴스 |
| --- | --- | --- |
| Brev 타입 | `verda_RTXPro6000` | `l40s-48gb.1x` |
| CPU | EPYC 9555, 가상 CPU 30개 | EPYC 9254, 가상 CPU 8개 |
| 관측 RAM | 약 88.4 GiB | 약 144.4 GiB |
| 운영체제 | Ubuntu 24.04, glibc 2.39 | Ubuntu 22.04, glibc 2.35 |
| NVIDIA 드라이버 | 580.126.09 | 565.57.01 |
| 카탈로그 시간당 견적 | $2.34 | $1.74 |

이번 두 seed에서 RTX 인스턴스의 학습 시간이 짧았다. CPU·RAM·운영체제·드라이버도 다른 인스턴스 설정의 비교이므로 GPU 자체의 효과를 분리하지 않았다. 정상 학습 처리량을 에이전트의 진단·교정·회복 성능으로 해석하지 않는다.

견적과 청구액을 구분한다. 공개 집계의 비용은 VM 생존 시간에 카탈로그 견적을 곱한 값이며, 설치와 대기 시간도 포함한다. 공급자의 실제 청구액과 저장소 과금은 확인하지 않았다.

## 실행과 결과의 결합

[측정 자식](../bench/brev_compute_probe_v1.py)은 학습이 반환된 뒤 앱을 닫기 전에 완료 영수증을 쓴다. [부모 실행기](../bench/brev_compute_parent_v1.py)는 프로토콜·단계·소스 해시와 Isaac Lab의 커밋·추적 파일 상태를 확인하고, 종료 코드·시간 초과·GPU 정리·영수증 내용을 모두 검사한다. 환경 버전, CUDA 장치, 작업, 환경 수, 관측한 학습 횟수와 체크포인트 해시가 맞아야 완료로 판정한다.

두 인스턴스의 다섯 단계가 모두 통과했다. 원본 영수증과 체크포인트를 회수해 SHA-256을 확인했다. 공개 파일에서는 체크포인트 경로를 Isaac Lab 기준 상대 경로로 바꿨으며, 원본 해시와 공개 파일 해시를 구분해 남겼다. 모델 API는 호출하지 않았다.

파일 회수 뒤 두 파일럿 VM을 삭제했고, 소유 인스턴스 ID가 목록에서 사라진 것과 비용 감시기 종료를 확인했다.

CPU 회귀는 Windows에서 31개 통과·Linux 전용 4개 건너뜀, WSL Linux에서 35개 통과였다. Ruff와 Linux 대상 Pyright 검사도 통과했다.

반복 실행용 인스턴스는 Stop 지원형을 선택한다. 이 파일럿의 RTX 결과는 Stop 미지원 Verda 구성에서 얻었으며, Stop 지원 RTX 구성은 별도 확인 대상이다.
