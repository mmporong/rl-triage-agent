# 다섯 유형의 새 학습 원천

진단 비교에 쓸 10사례와 정상 참조를 만들었다. Go2 평지 보행 정책 20개를 각각 300회 학습하고, 정책마다 같은 26조건 고정 평가를 수행했다. 체크포인트 바이트는 20개 모두 다르며, 사례 정책 10개의 체크포인트도 서로 다르다.

이 자료는 알려진 결함 유형에 새 seed를 적용한 입력이다. 설계자는 같은 결함 계열의 기존 결과를 참고했다. 원천 수집 단계의 모델 호출과 교정 실행은 각각 0회다. 검사 선택과 교정 후 회복은 후속 실행에서 평가한다.

## 사례 구성과 원천 판정

| 사례 | 유형 | 건수 | 고정 평가에 따른 분류 |
|---|---|---:|---|
| case-01·02 | 정상 NONE | 2 | eligible |
| case-03·04 | 보상 F1 | 2 | eligible |
| case-05·06 | 모터 F2 | 2 | eligible |
| case-07·08 | 보상·갱신 복합 F1+R1 | 2 | eligible |
| case-09·10 | 마찰 F5 | 2 | out_of_support |

계획 10건을 모두 보존했고 제외는 0건이다. `eligible`은 원천이 비교 조건을 충족했다는 뜻이다. 진단 성공을 뜻하지 않는다. F5 두 건은 진단 대상에 포함하되 등록 교정 범위 밖으로 유지한다.

정상 사례 두 건은 다른 seed의 정상 정책을 참조한다. 결함 사례 여덟 건은 같은 seed의 별도 정상 학습을 참조한다. 사례와 참조가 같은 체크포인트를 쓰는 자기 비교는 없다. 같은 사례를 여러 정책으로 진단해도 독립 사례 수는 늘어나지 않는다.

## 공개 자료와 모델 입력

공개 묶음은 JSON 63개다. 익명 원천 `source-01`부터 `source-20`까지 각각 고정 평가, 학습 곡선, SHA 근거 파일을 제공하고 전체 요약·provenance·manifest를 함께 둔다. 학습 곡선은 등록된 24개 지표의 300개 관측값과 원래 요약값을 보존한다. 체크포인트·이벤트·비공개 실행 원문은 복사하지 않는다.

모델용 수치 입력은 사례 24개와 참조 24개, 총 48개 학습 지표다. 결함 정답·고정 평가 판정·seed·물리 파일 경로는 모델 packet에 넣지 않는다. 검사 호스트가 쓰는 runtime 사실 16개는 이 수집 단계에서 미관측으로 남는다. 가용성 두 값은 false, 횟수에 해당하는 나머지 14개 값은 null이다. 설정된 epoch·미니배치 수를 실제 갱신 횟수로 바꾸지 않는다.

## 같은 Play의 영상과 수치

녹화 18개와 교정 미지원 표식 2건을 결합해 사례 입력 10쌍을 만들었다. 녹화마다 625프레임·50fps·12.5초이며 같은 시각의 상태·관절·토크 기록과 렌더 동기화 근거를 묶었다. F2는 전체 12관절의 토크 곡선 결함을 재생 때도 적용하고 복원을 확인했다. F5 사례에는 대체 영상을 만들지 않았다.

영상이 있는 사례의 두 모델 방식에는 학습 지표 48개와 같은 Play 수치 54개를 함께 준다. 프레임 방식에만 사례 3장·참조 3장을 더한다. 모델 응답과 무관하게 등록 순서의 첫 F1·F2 쌍을 아래 입력 미리보기로 공개한다. 교정·회복 영상이나 영상 효과의 근거가 아니다.

| 항목 | 기록 |

| 학습 owned 실행 시간 합 | 10,188.232초 |
| 고정 평가 owned 실행 시간 합 | 963.857초 |

별도 입장 smoke는 위 40회에 포함하지 않는다. smoke 한 번을 더한 원천 단계 SDK 실행은 41회다. 표의 시간은 실행·종료·소유 프로세스 정리를 포함한 기록이며, GPU 전용 계산 시간이나 진단 비용 절감률로 해석하지 않는다.

## 공개 파일 확인

저장소 루트에서 파일 목록·SHA·크기·공개 경로 검사를 재실행할 수 있다.

```bash
cd "$HOME/rl-triage-agent"
python -B -c 'from pathlib import Path; from evals.export_lineage_source_collection_v2 import verify_export; print(verify_export(Path("evals/results/five_type_sources_s2550_s2559_20261101_v1"))["status"])'
```

예상 출력은 `complete`다. 이 명령은 공개 묶음의 무결성을 확인한다. 학습과 GPU 평가는 원천 수집 사전등록에 정의돼 있다.
